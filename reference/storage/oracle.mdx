## Lifecycle

| Operation | OracleDb | AsyncOracleDb |
|-----------|----------|---------------|
| Initialization | Can connect during construction for schema validation and capability detection. | Defers schema validation and capability detection until first table access. |
| Engine | Synchronous SQLAlchemy engine. | SQLAlchemy `AsyncEngine`. |
| Cleanup | `db.close()` | `await db.close()` |

Close the database after all operations and shared-engine borrowers finish.

Bulk upserts on `OracleDb` process records individually. With `AsyncOracleDb`, await `upsert_session()` or `upsert_user_memory()` for each record.
